# 測驗選項生成方案比較



## 方案概述

| | 方案 A：即時生成 | 方案 B：預先生成 |
|---|---|---|
| **運作方式** | 學生測驗時即時呼叫 API | 管理者事先生成，學生直接讀取 |
| **API 呼叫時機** | 每次學生測驗 | 一次性（或新增單字時） |

---

## 成本比較（14,000 筆單字）

| | 方案 A | 方案 B |
|---|---|---|
| **初期成本** | $0 | **NT$15,400**（14,000 字） |
| **每月營運成本** | 依使用量成長 | $0 |
| **100 學生/月** | ~NT$11,000/月 | $0 |
| **500 學生/月** | ~NT$55,000/月 | $0 |
| **1,000 學生/月** | ~NT$110,000/月 | $0 |
| **新增 1,000 字** | $0（隨使用產生） | ~NT$1,100（一次性） |

**損益平衡點**：約 **140 位學生**使用後，方案 B 開始划算

---

## 使用體驗比較

| | 方案 A | 方案 B |
|---|---|---|
| **題目載入速度** | 2-5 秒（等待 API） | 即時（已預存） |
| **離線使用** | ❌ 不可 | ✅ 可以 |
| **網路不穩時** | 降級為本地選項 | 正常運作 |
| **學生體驗** | 可能感受到延遲 | 流暢無感 |

---

## 技術與維護比較

| | 方案 A | 方案 B |
|---|---|---|
| **實作複雜度** | 中等（需處理 loading、錯誤） | 簡單（讀取 JSON） |
| **Rate Limit 風險** | 高（30次/15分鐘，多人同時使用會撞限制） | 無 |
| **API 服務中斷時** | 降級為本地選項 | 不受影響 |
| **維護成本** | 需監控 API 使用量 | 低 |
| **新增單字流程** | 自動（隨使用生成） | 需執行腳本（約 30 秒/字） |

---

## 品質控管比較

| | 方案 A | 方案 B |
|---|---|---|
| **選項品質審核** | ❌ 無法事先審核 | ✅ 可人工審核 |
| **發現錯誤時** | 無法修正（每次重新生成） | 可手動修正 JSON |
| **一致性** | 同題目可能產生不同選項 | 固定選項，學生討論時一致 |
| **品質保證** | 依賴 GPT-4 即時輸出 | 可事先驗證 |

---

## 擴展性比較

| | 方案 A | 方案 B |
|---|---|---|
| **學生數量增加** | 成本線性增加 | 無影響 |
| **單字數量增加** | 無額外成本 | 需執行生成腳本 |
| **多產品共用** | 各產品分別計費 | 生成一次，多處使用 |

---

## 風險分析

| 風險 | 方案 A | 方案 B |
|---|---|---|
| **API 費用失控** | ⚠️ 高（難預測使用量） | ✅ 低（固定 NT$15,400） |
| **服務中斷** | ⚠️ 中（有降級機制） | ✅ 低 |
| **資料過時** | ✅ 低（即時生成） | ⚠️ 中（需定期更新） |
| **技術債務** | ⚠️ 中（需維護 API 邏輯） | ✅ 低 |

---

## 預算摘要

| 方案 | 初期投入 | 第一年成本（500學生/月） | 第二年成本 |
|-----|---------|------------------------|-----------|
| **A** | $0 | NT$660,000 | NT$660,000 |
| **B** | NT$15,400 | NT$15,400 | ~NT$2,200（新增字） |

---

## 適用場景

**方案 A 適合**：
- 學生數量極少（< 50 人/月）
- 測試階段，不確定是否長期使用
- 預算按月編列，無法一次支出

**方案 B 適合**：
- 學生數量 > 140 人
- 正式營運產品
- 重視使用體驗（載入速度）
- 需要品質審核
- 希望成本可預測

---

## 建議

以 WordGym 的情況（14,000 單字、教育產品）：

| 條件 | 推薦方案 |
|-----|---------|
| 學生 < 140 人/月 | 方案 A |
| 學生 ≥ 140 人/月 | **方案 B** |
| 重視品質控管 | **方案 B** |
| 重視載入速度 | **方案 B** |

---

## 技術細節

### 使用模型
- GPT-4（品質最佳）
- 每題成本：約 NT$1.1

### 生成內容
每個單字生成：
- 正確答案（依例句調整詞形）
- 3 個干擾選項（含錯誤類型說明）
- 文法考點說明

### 干擾選項類型
- 類型 A：詞形錯誤（時態/單複數）
- 類型 B：詞性錯誤
- 類型 C：語意相反
- 類型 D：拼寫易混淆
- 類型 E：發音相似
- 類型 F：搭配錯誤
